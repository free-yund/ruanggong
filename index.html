一句话：把散落的东西整理成能检索的结构

我是四川大学计算机科学与技术专业的本科生。学习之外，我花最多时间在两件事上： 写课程要求的系统，和把课程资料整理得不那么难找。

前者让我熟悉了 Java + Spring Boot 那一套：分层、事务、拦截器、 统一返回体；后者让我做了一个多维标签检索网站——把课件、试卷、习题按 「课程 × 考试类型 × 资料类型 × 年份」打标签，用标签交集代替翻聊天记录。

写小游戏是另一种训练：pygame 没有框架帮你兜底， 碰撞、刷怪、资源加载、缩放都得自己算。600 行的《潜艇大战》是我第一个「从零跑通」的东西， 也是我第一次意识到——能把状态想清楚，比写得多更重要。

01

课件资料多维智能标签检索网站

课程设计 · 后端 + 架构设计 · Spring Boot / Vue 3

把「翻五个群找一张卷子」变成「选四个标签直接命中」。先写概要设计说明书（GB/T 8567 格式）， 再做实现：8 个模块、13 张表、多标签交集检索。

  • 多标签交集用一条 SQL 解决：GROUP BY resource_id HAVING COUNT(DISTINCT tag_id) = N
  • 资源状态机 UPLOADING → PROCESSING → ACTIVE，先落文件再提交状态，避免孤儿数据
  • 安全落在表结构上：BCrypt 自含盐、连续失败 5 次锁 15 分钟、SHA-256 去重
